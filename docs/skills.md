# 技能路径

面向安全工程实践的成长路线：从基础到进阶，再到自动化与 AI 赋能。

## 网络安全基础
- 架构与分区、最小权限、零信任思维
- 流量治理与访问控制、日志与告警

## Check Point 精进
- Policy 设计与变更治理（对象、层、规则基线）
- Infinity Portal 与 API（令牌、调用、自动化）
- Threat 家族与客户端套件实践
- 实战示例：
  - [Remote Access VPN 自动加载代理脚本](posts/remote-access-vpn-auto-proxy-20250102.md)
  - [AIOps 智能运维实践](posts/aiops-20260308.md)

## 云安全路线
- AWS/Azure 安全基线与合规
- 身份与网络边界、WAF 与防护策略

## AI + Security
- 自动化脚本与运维（AIOps）
- 检测与响应工作流的智能化
